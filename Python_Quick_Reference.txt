COMMON PATTERNS:

Load Dictionary from File:
def load_data(filename):
    data = {}
    with open(filename, "r") as file:
        for line in file:
            parts = line.strip().split(",")
            key = parts[0]
            value = parts[1]
            data[key] = value
    return data

Save Dictionary to File:
def save_data(data, filename):
    with open(filename, "w") as file:
        for key, value in data.items():
            line = f"{key},{value}\n"
            file.write(line)

Safe User Input:
def get_number():
    while True:
        try:
            return int(input("Enter number: "))
        except ValueError:
            print("Invalid! Try again.")

Calculate Average:
average = sum(numbers) / len(numbers)

Filter and Transform:
# Get doubled positive numbers
result = [x * 2 for x in numbers if x > 0]

QUICK TIPS:
1) Use 'with open()' for files (auto-closes)
2) Use '.items()' when looping dictionaries
3) Use comprehensions for simple transformations
4) Always handle errors for file operations
5) Convert to string before joining: str(x)
6) Use f-strings for formatting: f"{var}
7) Check 'if key in dict' before accessing
8) Use 'try/except' for risky operations
