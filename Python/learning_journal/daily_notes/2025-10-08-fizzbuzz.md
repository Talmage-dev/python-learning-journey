#Tesing with pytest
- Test files must start with 'test_'
- Test functions must start with 'test_'
- Use 'assert' to verify expected behavior
- Run with 'pytest -v' for verbose output
- Parametrized tests with '@pytest.mark.parametrize'
#Key Insights
1) Why check % 15 first? Because 15 is divisible by both 3 and 5, so checking % 3 first would return "Fizz" instead of "FizzBuzz"
2) range(1, n+1) generates 1 to n inclusive (not 0 to n-1)
3) Convert to strings for consistent return type.
