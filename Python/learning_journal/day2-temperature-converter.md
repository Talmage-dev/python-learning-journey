What I Learned:
# User Input & Type Conversion
- 'input()' always returns a string
- 'try/except ValueError' catches conversion errors
- F-strings format output: 'f"{value:.2f}"' for 2 decimals

# Function Design
- Break complex logic into small functions
- Each function does one thing well
- Functions can call other functions
- Docstrings explain purpose and formulas

# Testing Strategy
- Test basic cases (0, 100, common values)
- Test edge cases (-40, absolute zero)
- Test error conditions (invalid units)
- Parameterized tests reduce repetition
- Group related tests in classes

# Key Formulas
- C to F: (C x 9/5) + 32
- F to C: (F -32) x 5/9
- C to K: C + 273.15
- K to C: K - 273.15
