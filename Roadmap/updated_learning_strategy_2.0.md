# Learning Strategy v2.0 - Mastery-Focused Approach

## Date Created: October 31, 2025
## Philosophy: Quality Over Speed, Mastery Over Coverage

---

## Core Principles

### 1. Priorities (In Order):
1. **Gain skills and KEEP them** - Deep understanding and retention
2. **Complete all roadmap goals** - MIT-level knowledge
3. **Timeline is flexible** - 1 year, 3 years, 5 years - doesn't matter

### 2. The Basketball Model:
- **Learn** → **Practice Daily** → **Master** → **Maintain Forever**
- Just like learning to dribble: intensive practice until automatic, then daily maintenance

### 3. Never Forget:
- Once learned, practice until mastered
- Once mastered, maintain forever
- No more "refreshers" - skills stay sharp

---

## Daily Structure (2-4 hours total)

### Morning Session (45-60 minutes)

#### 1. Review Yesterday (5 min)
- Look at yesterday's performance review
- Identify what needs attention today
- Check for patterns or blockers

#### 2. Review Today's Objectives (2 min)
- Check objectives created last night
- Confirm they're still appropriate
- Make any needed adjustments

#### 3. Typing Practice (15 min)
- Keybr.com for focused practice
- Track WPM and accuracy
- Focus on weak keys

#### 4. Warm-Up Rotation (15 min)
- Pick from maintenance list (see rotation schedule)
- Write 2-3 key methods from memory
- Solve 1 quick problem
- Goal: Keep mastered skills sharp (5-10 min per structure)

#### 5. Intensive Practice (30-40 min)
- Focus on current weak areas
- Deep, focused practice
- Multiple activities (see Intensive Practice section)
- Goal: Move skills from weak to mastered

---

### Main Learning Session (1.5-2.5 hours)

#### 6. New Learning
- Today's new topic or concept
- Deep dive with examples
- Initial implementation
- Understanding before memorization

---

### Evening Session (10-15 minutes)

#### 7. Evening Drill
- Quick practice of today's topic
- Solidify what was learned
- Test understanding

#### 8. Daily Review & Planning (10 min)
- **Review Performance** (5 min):
  - Score each objective (✅/⚠️/❌)
  - Calculate daily score
  - Identify what went well and what struggled
  
- **Make Decision** (2 min):
  - Move forward as planned?
  - Need extra practice tomorrow?
  - Adjust approach?
  
- **Create Tomorrow's Objectives** (3 min):
  - Based on today's performance
  - Set specific, measurable goals
  - Plan adjustments if needed

## The Three Practice Phases

### Phase 1: 🔴 Learning (Initial Exposure)

**When:** First time encountering a topic

**Duration:** 2-4 hours (one session)

**Activities:**
- Understand the concept
- See examples
- Initial implementation
- Ask questions

**Goal:** Basic understanding

**Next Step:** Move immediately to Intensive Practice

---

### Phase 2: 🟡 Intensive Practice (Building Mastery)

**When:** Right after learning something new

**Duration:** 30-40 minutes daily for 1-2 weeks

**Activities:**

**Activity 1: Speed Writing (10 min)**
- Write all methods/algorithms from memory
- Time yourself
- Repeat 2-3 times
- Goal: Under 5 minutes eventually

**Activity 2: Use Cases (15 min)**
- Implement 2-3 real-world applications
- Different scenarios each day
- Build pattern library
- Focus on "when to use"

**Activity 3: Problem Solving (15 min)**
- Solve 1-2 problems using the structure/algorithm
- LeetCode, HackerRank, or custom problems
- Timed challenges
- Analyze solutions

**Goal:** Automatic recall, no thinking required

**Success Criteria (Move to Maintenance when):**
- Can write all methods without thinking
- Use cases feel natural
- Solve problems confidently
- Daily scores 90%+ for this topic
- Usually after 1-2 weeks of daily practice

---

### Phase 3: 🟢 Maintenance (Forever)

**When:** After mastery achieved

**Duration:** 5-10 minutes daily (in rotation)

**Activities:**
- Write 2-3 key methods (3 min)
- Solve 1 problem (5 min)
- Quick review of use cases (2 min)

**Goal:** Never forget, always sharp

**Rotation Schedule:**
- Monday: Stack
- Tuesday: Queue
- Wednesday: Singly Linked List
- Thursday: Doubly Linked List
- Friday: Binary Search Tree
- Saturday: Hash Tables (once mastered)
- Sunday: Graphs (once mastered)

**Note:** As you master more structures, rotation expands. Each structure gets practiced at least once per week.

### Morning: Review Objectives (2 min)

```

```

---

### Evening: Review & Score (10 min)

#### Step 1: Score Each Objective (5 min)

**Achievement Levels:**

✅ **ACHIEVED** (1.0 point)
- Completed fully
- Met or exceeded target
- Feel confident

⚠️ **PARTIAL** (0.5 point)
- Made progress but didn't complete
- Close to target
- Need a bit more work

❌ **NOT ACHIEVED** (0 point)
- Didn't complete
- Far from target
- Struggled significantly

**Calculate Daily Score:** Total points / Total objectives = X/6 (%)

---

#### Step 2: Interpret Score (2 min)

**90-100% (5.4-6.0/6):** 🔥 Excellent day!
- Move forward as planned
- Consider increasing difficulty
- Celebrate progress!

**75-89% (4.5-5.3/6):** ✅ Good day!
- Move forward as planned
- Note weak areas for tomorrow
- Solid progress

**60-74% (3.6-4.4/6):** ⚠️ Okay day
- Move forward BUT add extra practice
- Review what went wrong
- Adjust approach if needed

**Below 60% (<3.6/6):** 🔄 Needs attention
- DON'T move to new topics yet
- Extra practice day tomorrow
- Identify and address blockers

---

#### Step 3: Create Tomorrow's Objectives (3 min)

Based on today's performance:

**If score ≥ 75%:**
- Continue as planned
- Add any needed adjustments
- Set new learning objectives

**If score 60-74%:**
- Continue but add extra practice
- Repeat any ⚠️ objectives
- Reduce new content slightly

**If score < 60%:**
- Focus on today's weak areas
- Minimal or no new content
- Extra practice day

- When mastery reaches 90%+
- Daily scores 90%+ for this topic

**🟢 Maintenance → 🟡 Intensive Practice:**
- If mastery drops below 80%

## Flexible Roadmap Approach

### Milestone-Based (Not Date-Based)

**Instead of:**
```
Week 5-6: Data Structures (MUST finish by Nov 23)
Week 7-8: Advanced Python (MUST finish by Dec 12)
```

**Use:**
```
Milestone 2: Data Structures
Status: In Progress
Mastery Level: 85%
Estimated Completion: When ready (2-4 weeks remaining)

Milestone 3: Advanced Python
Start: After Milestone 2 reaches 90%+
```

---

### Milestone Completion Criteria:

**A milestone is complete when:**
- All topics within milestone at 90%+ mastery
- Weekly average scores 85%+
- Feel confident and ready to move on
- No major weak areas remaining

**Don't move on if:**
- Any topic below 80% mastery
- Weekly average below 75%
- Feel uncertain or confused
- Significant weak areas remain

---

### Timeline Adjustments:

**Review timeline weekly:**
- Compare actual vs planned progress
- Adjust estimates based on reality
- No stress about changes
- Focus on mastery, not deadlines

**When behind schedule:**
- Assess why (too fast? too hard? life events?)
- Adjust timeline accordingly
- Add extra practice time
- No guilt - quality matters!

**When ahead of schedule:**
- Great! But don't rush
- Use extra time for deeper mastery
- Add advanced topics
- Build more projects
