**Time:** ~After lunch - afternoon session

**Goal for today:** Learn and master Insertion Sort (3rd sorting algorithm)

---

#### Understanding Phase:

**Key Concepts Learned:**

1. **Real-world analogy:** Sorting playing cards in your hand
   - Pick up cards one at a time
   - Insert each into correct position
   - Build sorted hand incrementally

2. **The core idea:**
   - Array divided into sorted | unsorted portions
   - Take first unsorted element
   - Insert into correct position in sorted portion
   - Sorted portion grows by 1 each pass

3. **The shifting process (KEY):**
   - Compare new element with sorted portion (right to left)
   - Shift larger elements right
   - Insert new element in opened space
   - Like making space on a crowded shelf

4. **Visual understanding:**
   - EXCELLENT step-by-step visuals provided!
   - Saw exact array states at each step
   - Understood variable roles (i, j, current)
   - Traced through example: [5,2,8,1,9]

---

#### Initial Implementation:

**First attempt:**
```python
def insertion_sort(ar):
    n = len(ar)
    
    for i in range(1, n):
        current = ar[i]
        j = i - 1
        
        while j >= 0 and ar[j] > current:
            ar[j + 1] = ar[j]
            j -= 1
        
        ar[j + 1] = current
    
    return[ar]  # ← Bug: extra brackets!
```

**Mistake:** Returned `[ar]` instead of `ar`
**Fixed immediately:** Changed to `return ar`

**Result:** ✅ Perfect after one-character fix!

#### Comparison/Analysis:

**How is this different from Bubble/Selection?**

**Bubble Sort:**
- Compare adjacent elements
- Many swaps per pass
- Large elements "bubble" to end

**Selection Sort:**
- Find minimum each pass
- One swap per pass
- Smallest elements go to front

**Insertion Sort:**
- Build sorted portion incrementally
- Insert each element in correct position
- Shift elements to make space

**When to use Insertion Sort:**
- ✅ Array is nearly sorted (O(n) best case!)
- ✅ Small datasets
- ✅ Building sorted list in real-time (online)
- ✅ Need stable sort

**Time Complexity:**
- Best: O(n) - already sorted
- Average: O(n²)
- Worst: O(n²) - reverse sorted

**Space Complexity:**
- O(1) - sorts in place
