#### Use Case 1: `isomorphic_strings(s, t)` (~15 min)

**Problem:** Check if two strings are isomorphic (same pattern)

**Initial Approach:**
- Got stuck on timer (15 min)
- Started thinking about checking characters
- Wasn't sure how to implement the logic

**After Explanation:**
- Understood: Need TWO hash tables (bidirectional mapping)
- Key insight: Check mappings WHILE creating them (not after)
- Pattern: Bidirectional Mapping (s→t AND t→s)

**Implementation:**
```python
def isomorphic_strings(s, t):
    s_to_t = HashTable(len(s))
    t_to_s = HashTable(len(t))
    
    for i in range(len(s)):
        char_s = s[i]
        char_t = t[i]
        
        # Check forward mapping
        mapped_t = s_to_t.get(char_s)
        if mapped_t is not None:
            if mapped_t != char_t:
                return False
        else:
            s_to_t.insert(char_s, char_t)
        
        # Check reverse mapping
        mapped_s = t_to_s.get(char_t)
        if mapped_s is not None:
            if mapped_s != char_s:
                return False
        else:
            t_to_s.insert(char_t, char_s)
    
    return True
```

**Result:** ✅ All tests passed!

**Key Learning:**
- Hash tables can map in both directions
- Need to verify BOTH mappings for consistency
- Check as you insert (not after)
- This is "Bidirectional Mapping" pattern

**Bugs Fixed:**
- Typo in import path: `Coode` → `Code`
- Used `range(s)` instead of `range(len(s))`
- After fixes: Perfect! ✅

**Initial Approach:**

- Made one typo: `arr[1]` instead of `arr[i]`

**Implementation:**
```python
def contains_duplicate_within_k(arr, k):
    ht = HashTable(len(arr))
    
    for i in range(len(arr)):
        num = arr[i]  # Fixed: was arr[1]
        
        last_index = ht.get(num)
        if last_index is not None:
            distance = i - last_index
            if distance <= k:
                return True
        
        ht.insert(num, i)
    
    return False
```

#### Method 1: Degree Functions (15-20 min)

**Learned:** Three degree functions for directed graphs

**Concepts:**
- **Out-degree:** Edges going OUT from node
- **In-degree:** Edges coming IN to node  
- **Total degree:** Out + In

**Implementation:**

**`out_degree(node)` - EASY:**
```python
def out_degree(self, node):
    if node not in self.graph:
        return 0
    return len(self.graph[node])
```
- Just count length of adjacency list!
- Already have this in our structure
- Time: O(1)

**`in_degree(node)` - Search Required:**
```python
def in_degree(self, node):
    count = 0
    for vertex in self.graph:
        if node in self.graph[vertex]:
            count += 1
    return count
```
- Need to check ALL vertices
- See who has this node in their list
- Time: O(V) where V = number of vertices

**`degree(node)` - Combine:**
```python
def degree(self, node):
    return self.out_degree(node) + self.in_degree(node)
```
- Simple addition
- Total connections to/from node

**Initial Note:**
- Started with UNDIRECTED add_edge (adding both directions)
- Clarified: Should use DIRECTED for most problems
- Updated to directed edges only

#### Method 2: Cycle Detection `has_cycle()` (30-40 min)

**Problem:** Detect if directed graph has a cycle

**Concept Learned:** THREE states for DFS

**States:**
- **UNVISITED (0):** Haven't seen this node
- **VISITING (1):** Currently exploring this path
- **VISITED (2):** Completely done with this node

**Why three states?**
- Two states isn't enough!
- Need to know: "Is this on my CURRENT path?" vs "Did I visit earlier?"
- VISITING = on current path = if we see it again, CYCLE!
- VISITED = explored fully, not on current path = no cycle

**Visual Understanding:**

Cycle example:
```
A → B → C
↑       ↓
←   D  ←

DFS from A:
A=VISITING → B=VISITING → C=VISITING → D=VISITING
D points to A... A is VISITING! → CYCLE FOUND!
```

No cycle example:
```
A → B → C
    ↓
    D

DFS from A:
A=VISITING → B=VISITING → C=VISITING → (no neighbors) → C=VISITED
→ D=VISITING → (no neighbors) → D=VISITED
→ B=VISITED → A=VISITED
No VISITING nodes on current path → No cycle
```

**Implementation:**
```python
def has_cycle(self):
    UNVISITED = 0
    VISITING = 1
    VISITED = 2
    
    state = {}
    for node in self.graph:
        state[node] = UNVISITED
    
    def dfs(node):
        state[node] = VISITING
        
        for neighbour in self.graph[node]:
            if state[neighbour] == VISITING:
                return True  # Cycle!
            if state[neighbour] == UNVISITED:
                if dfs(neighbour):
                    return True
        
        state[node] = VISITED
        return False
    
    for node in self.graph:
        if state[node] == UNVISITED:
            if dfs(node):
                return True
    
    return False
```

**Result:** ✅ Perfect implementation on first try! 20 minutes!

**All Tests Passed:**
```
Test 1: A→B→C→D→A (cycle) → True ✅
Test 2: A→B→C, B→D (tree) → False ✅
Test 3: A→A (self-loop) → True ✅
Test 4: Disconnected with cycle → True ✅
```

**Key Learning:**
- DFS with state tracking
- Recursive helper function
- Handle disconnected graphs (loop through all nodes)
- This is medium-hard algorithm - nailed it!

**Understanding:**
- Clear on why three states needed
- Understand recursive DFS flow
