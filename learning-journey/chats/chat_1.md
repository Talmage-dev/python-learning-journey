## 🧠 The Key Insight:

You need **TWO passes** through the data:

### **Pass 1:** Put ALL numbers in the hash table first (just mark them as "seen")
```python
for num in nums:
    ht.insert(num, True)  # Just mark as existing
```

### **Pass 2:** For each number, check if it's the START of a sequence
- If `num - 1` does NOT exist → this is a start!
- Then count forward: `num`, `num+1`, `num+2`, etc.

---

## 💡 Here's the Complete Solution:

```python
def longest_consecutive_sequence(nums):
    if not nums:
        return 0
    
    # Pass 1: Add all numbers to hash table
    ht = HashTable(len(nums))
    for num in nums:
        ht.insert(num, True)  # Pattern: SEEN (just checking existence)
    
    longest = 0
    
    # Pass 2: Find sequences
    for num in nums:
        # Check if this is the START of a sequence
        if ht.get(num - 1) is None:  # num-1 doesn't exist, so num is a start!
            current_num = num
            current_length = 1
            
            # Count forward from this start
            while ht.get(current_num + 1) is not None:
                current_num += 1
                current_length += 1
            
            # Update longest if this sequence is longer
            longest = max(longest, current_length)
    
    return longest
```

---

## 🔍 How It Works:

**Example:** `[100, 4, 200, 1, 3, 2]`

**Pass 1:** Hash table has: {100, 4, 200, 1, 3, 2}

**Pass 2:**
- `100`: Is 99 in table? No → START! Count: 100 (length 1)
- `4`: Is 3 in table? Yes → NOT a start, skip
- `200`: Is 199 in table? No → START! Count: 200 (length 1)
- `1`: Is 0 in table? No → START! Count: 1→2→3→4 (length 4) ✅
- `3`: Is 2 in table? Yes → NOT a start, skip
- `2`: Is 1 in table? Yes → NOT a start, skip

**Result:** Longest = 4

---

## 📊 Pattern & Complexity:

**Pattern:** **SEEN** (value = True, just checking existence)

**Time Complexity:** O(n) 
- Pass 1: O(n) to insert all
- Pass 2: O(n) - each number visited at most twice (once as potential start, once when counting)

**Space Complexity:** O(n) - storing all numbers

```python
def count_components(self):
    # Track visited nodes (only need 2 states, not 3!)
    visited = set()  # Simple set is easier
    count = 0
    
    # BFS helper to explore one component
    def bfs(start_node):
        queue = [start_node]
        visited.add(start_node)
        
        while queue:
            node = queue.pop(0)  # Or use deque with popleft()
            
            for neighbour in self.graph[node]:
                if neighbour not in visited:
                    visited.add(neighbour)
                    queue.append(neighbour)
    
    # Count components: start BFS from each unvisited node
    for node in self.graph:
        if node not in visited:
            bfs(node)  # Explore entire component
            count += 1  # That's one component!
    
    return count
```

---

## 🔍 How It Works:

**Example:** `A-B-C` and `D-E` (2 components)

1. Start with `visited = {}`, `count = 0`
2. Loop through nodes: A, B, C, D, E
3. **Node A:** Not visited → BFS from A (visits A, B, C) → `count = 1`
4. **Node B:** Already visited → skip
5. **Node C:** Already visited → skip
6. **Node D:** Not visited → BFS from D (visits D, E) → `count = 2`
7. **Node E:** Already visited → skip
8. Return `count = 2` ✅

def insertion_sort(ar):
    n = len(ar)
    for i in range(1, n):
        current = ar[i]
        j = i - 1

        while j >= 0 and ar[j] > current:
            ar[j + 1] = ar[j]  # Shift right
            j -= 1

## 1️⃣ **`set()` - What is it?**

A **set** is a Python data structure that stores **unique items** with **no duplicates** and **no order**.

### **Think of it like:**
- A hash table that only stores keys (no values)
- Super fast lookup: O(1) to check if something exists
- Automatically removes duplicates

- ✅ Fast membership checking (`if x in set`)
- ✅ Remove duplicates from a list
- ❌ Don't use if you need order or duplicates

## 2️⃣ **`//` - Floor Division (Integer Division)**

The `//` operator divides and **rounds DOWN** to the nearest integer.

### **Examples:**

```python
# Regular division (/)
10 / 3  # → 3.333333...
7 / 2   # → 3.5

# Floor division (//)
10 // 3  # → 3 (rounds down from 3.33)
7 // 2   # → 3 (rounds down from 3.5)
9 // 2   # → 4 (rounds down from 4.5)
4 // 2   # → 2 (exact, no rounding needed)
```

### **In our problem:**
```python
# [1, 1, 1, 1], target = 2
# Element 1 appears 4 times
# How many pairs of (1, 1) can we make?

pairs = 4 // 2  # → 2 pairs
# We can make 2 pairs: (1,1) and (1,1)
```

**Why `//` instead of `/`?**
- We want whole pairs, not fractions!
- `4 / 2 = 2.0` (float)
- `4 // 2 = 2` (integer)
